## 更新与改进

- 应用由 JSONPal 更名为 MyJson，从 Electron 重构为 Go 和 MyGo，并重新设计界面与应用图标。
- 保留 JSON 格式化、压缩、转义、去转义、字段排序、多标签编辑和差异对比功能。
- 格式化、压缩和字段排序会保留数字原文，避免大整数因数字精度限制而发生变化。
- 字段排序会递归处理对象，并保留数组顺序。
- 差异对比支持并排或合并显示，并可选择按字符或单词高亮差异。
- 新增浅色、深色及跟随系统的外观选择，可分别调整浅色和深色配色，并支持界面缩放。
- 重新设计设置页，支持调整编辑器字号、行高、缩进、换行、空白字符显示等选项。

## 升级注意事项

- 旧版设置不会自动迁移，升级后请在 MyJson 中重新设置。部分旧版编辑器设置不再提供。
- 重新实现的侧边栏暂不支持标签重命名、拖动排序，以及关闭其他或全部标签。
- JSON 校验更严格，包含重复对象键的内容在格式化、压缩或排序时会报错。

## 下载与安装

- macOS Apple Silicon：下载 `myjson-0.2.0-arm64.dmg`，打开后将 MyJson 拖入应用程序文件夹。
- Windows 64 位：下载 `myjson-setup-0.2.0-amd64.exe` 并运行安装程序。

## 已知限制

- 目前仅在 macOS 上经过测试，Windows 的运行时交互未测试。
- 应用未经过正式签名或公证，安装或打开时可能出现系统安全提示。
